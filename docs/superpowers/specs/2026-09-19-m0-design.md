# M0 Design: repository, PWA skeleton, controller test screen

Approved by the owner in chat on 2026-09-19. Implements milestone M0 of `docs/SPEC.md` section 11.

## Decisions taken for M0
- **Tooling (LOCKED):** Vite + Vitest, TypeScript strict. Service worker is hand-written (no PWA plugin) to keep dependencies few.
- **Hosting (LOCKED):** GitHub Pages. CSP is delivered as a `<meta>` tag because Pages cannot set headers. `frame-ancestors` cannot be enforced this way; accepted as low risk (no login, no data).
- **Controller test screen:** controller-agnostic. The owner tests with a different pad on PC than the 8BitDo used on the phone.

## Scope
1. Vite + TypeScript (strict) project with a pinned lockfile and the layout from SPEC section 10: `src/engine`, `src/bosses`, `src/game`, `src/ui`, `tests`, `docs`, `public`.
2. One screen: the controller test.
   - Lists every connected gamepad (there may be several).
   - For each: id string, `mapping` value (`"standard"` or empty), and every button (pressed, value) and axis, live.
   - A "copy report" button writes a plain-text report to the clipboard: user agent, gamepad id, mapping, button and axis counts, current values. Used to compare controllers and 8BitDo modes.
   - The report also lists which buttons were ever pressed and each axis's min/max since page load, because on the phone the copy button is tapped by finger while no controller button is held.
   - No network, no storage, no remapping.
3. Installable PWA: web manifest, icons, hand-written service worker that precaches the build so the app runs offline after first install.
4. Strict CSP meta tag: `default-src 'self'`, no inline script, no `unsafe-*` sources, `connect-src 'self'`.
5. Repo hygiene: `.gitignore` (node_modules, build output, exported stats and player data), Dependabot config, CI workflow (typecheck, tests, `npm audit`, build, deploy to GitHub Pages).
6. Docs: fill the Commands section of `CLAUDE.md`, mark tooling and hosting LOCKED in SPEC sections 3 and 12, add a short phone-testing note (PWA install needs HTTPS, so deploy to Pages first) with a manual S21 checklist.

## Tests
- Vitest, pure logic: gamepad snapshot to report text formatter; CSP meta tag is present and contains no `unsafe-*` source.
- Manual on the S21: controller screen with the 8BitDo in each mode, install to home screen, offline launch.

## Out of scope
Game loop, player, input mapping profiles, boss data, stats. Per-controller mapping profiles come with the button layout decision (SPEC section 5, OPEN).
